To refresh the gallery, use a disposable database with fictional players, complete several sessions to populate the profile and chemistry history, then capture each screen after loading and animations settle. Keep the filenames above so README links continue to work. Inspect the captures for clipped dialogs, loading indicators, and accidental personal data before replacing them.
